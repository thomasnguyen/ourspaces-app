# How to win (one page)

Rules: `HACKATHON_RULES.md`. Strategy: `HACKATHON_STRATEGY.md`.

## Table stakes (lose without these)
Public `convex.site` URL · public repo · `hackathon.md` via `/hackathon` ·
<3 min video · social post tagging @convex @OpenAI @firecrawl @agentmail ·
submitted on vibeapps.dev before Sep 22 12pm PT.

## What the judges actually reward (beyond the checklist)

**Convex (Jamie, Wayne, Shawn, Michael, Nicolas)**
- Sync-engine showpiece: two windows, one mutation, both update. Show it every
  30s of the video. Jamie's whole pitch is "sync platform" — be the poster child.
- Use the *new* stuff they want adoption on: Auth v2, components (AgentMail,
  Firecrawl, presence), crons, HTTP actions, AI Gateway. Name them in README.
- Wayne runs community + vibeapps.dev: past judging text says "less talk, more
  demo" and "bonus for social shares." Post early, post often, tag people.
- Past winners were everyday/vertical apps (PostIT, Relio CRM, InfoCapsule
  digest), not dev tools.

**OpenAI (4 judges)** — they want to see **Codex** as the builder. Build log
shows Codex sessions; README has a "built with Codex" section; use structured
outputs, not chat UI.

**AgentMail (Haakam, CEO)** — his line: "agents as first-class citizens,
starting with email." Give the *space* an identity and an inbox that sends,
receives, and acts. Two-way (replies mutate the canvas) = exactly his thesis.

**Firecrawl (Max Kelly)** — a URL becomes structured data that does something.
Promote-a-link → rich card / poll option; scraped venue details feed the email.

**Founders on the panel (ClarityCare, Vigil)** — vote for "would I use this
tomorrow" and a clear story. Holly on camera, real-people framing, no jargon.

## Non-obvious edges
- Judges skim 100+ entries: first 10s of video and the README hero screenshot
  decide. Open on the money shot, not a title card.
- Live URL must work cold: seeded public demo space, resets nightly.
- Two-person team with a real designer = polish nobody else has. Lean in.
- One line, everywhere: "Turn your group chat into a place. Forward it an
  email, drop it a link, and it remembers for everyone — live."
